GSC Data Analyzer

A personal, read-only reporting tool for Google Search Console.

What it does

GSC Data Analyzer is a small command-line script run on the developer's own computer. It reads search performance data (queries, pages, clicks, impressions, CTR and average position) from Google Search Console for websites the developer already has access to, and saves it as local files for SEO analysis and progress reports.

Who it is for

This tool is for the developer's personal use only. It is not offered to the public and has no sign-up, hosted service or user accounts.

Google permissions

  • It requests one scope: https://www.googleapis.com/auth/webmasters.readonly (view Search Console data).
  • It cannot change any Search Console settings, verify sites or manage users.
