Privacy Policy

GSC Data Analyzer · Last updated: October 6, 2026

Overview

GSC Data Analyzer is a personal command-line tool used only by its developer. It runs locally on the developer's own computer. There is no server, website backend or database operated by this app.

Data the app accesses

With the user's explicit consent through Google's OAuth screen, the app requests read-only access to Google Search Console (webmasters.readonly). It reads search performance data, such as queries, page URLs, clicks, impressions, click-through rate and average position, for properties the signed-in Google account can already view.

The app does not request access to Gmail, Google Drive, contacts or any other Google data, and it cannot modify Search Console settings.

How the data is used

Retrieved data is used only to produce SEO analysis and reports for the websites concerned. It is not used for advertising, profiling, or training machine learning models.

Storage

Search Console data and the OAuth token are stored only on the developer's local computer, with file permissions restricted to the developer's user account. Nothing is uploaded to servers controlled by this app.

Sharing

The app does not sell, rent or transfer Google user data to third parties. Aggregated findings may appear in reports for the website owner whose Search Console property the data comes from.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account › Third-party connections. Deleting the local token file also stops the app from accessing any data.

Contact

Questions about this policy: open an issue on the GitHub repository.
